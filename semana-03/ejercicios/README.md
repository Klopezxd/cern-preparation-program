# Ejercicios Prácticos – Semana 3

Este directorio documenta la resolución de las actividades y ejercicios prácticos de la Semana 3.

---

## 1. ROOT, uproot y CMS NanoAOD

* **Objetivo:** Inspeccionar y analizar datos de colisiones del CMS en formato NanoAOD:
  1. Uso de contenedores Docker oficiales para CMS Open Data y ejecución en entorno local.
  2. Apertura y lectura de árboles ROOT sin dependencias pesadas mediante `uproot` y `awkward-array`.
  3. Extracción de cinemática de partículas (muones: $p_T$, $\eta$, $\phi$, masa).
  4. Cálculo de masa invariante y generación de histogramas/visualizaciones físicas reproducibles.
* **Entregable:** Cuaderno interactivo Jupyter y evidencia técnica.

---

## 2. Trabajo Colaborativo en Git y GitHub

* **Objetivo:** Dominar el flujo de trabajo colaborativo distribuido:
  1. Creación y gestión de ramas de características (`feature branches`).
  2. Generación intencional y resolución analítica de conflictos de fusión (*merge conflicts*).
  3. Flujo formal de *Pull Request* (PR) y revisión de código (*Code Review*).

---

## 3. CV Técnico Internacional (Europass)

* **Objetivo:** Elaborar un currículum técnico en inglés alineado con los estándares del CERN:
  1. Redacción de proyectos de software y computación científica de alto impacto.
  2. Detalle del stack técnico, competencias analíticas y formación académica en TI (ESPE).
