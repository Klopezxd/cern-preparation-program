## 🎯 Objetivo Personal
Fortalecer competencias técnicas y prácticas en computación científica, procesamiento y análisis de datos masivos (Big Data), desarrollo colaborativo y entornos de contenerización, con miras a construir un perfil competitivo para postular al **CERN Summer Student Programme** y proyectos de investigación internacional.

* **Ciencia de Datos y Análisis:** Python (`uproot`, `awkward-array`, `pandas`, `matplotlib`), análisis de conjuntos de datos del LHC (NanoAOD).
* **Entornos y Contenerización:** Linux (WSL2 / Ubuntu), Docker Engine, automatización de entornos reproducibles.
* **Control de Versiones y Trabajo Colaborativo:** Git, GitHub (ramas, Pull Requests, resolución de conflictos, integración continua).
* **Computación Científica:** C++, ROOT, análisis de datos de física de altas energías (CMS Open Data).
