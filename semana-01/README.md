# Semana 1 — Introducción a CMS Open Data

* **Periodo:** 31 de agosto al 4 de septiembre de 2026
* **Modalidad:** Trabajo autónomo (6 horas)
* **Objetivo:** Familiarizarse con el portal de datos abiertos del experimento CMS (CERN), comprender la organización de datasets de colisiones y simulaciones Monte Carlo, y consolidar el uso profesional de Git y GitHub para el registro de evidencias.
