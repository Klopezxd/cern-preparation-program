# Ejercicios Prácticos – Semana 1

Este directorio documenta la resolución de los ejercicios técnicos correspondientes a la Semana 1.

---

## 1. GitHub Skills: Introduction to GitHub
* **Repositorio:** [Klopezxd/skills-introduction-to-github](https://github.com/Klopezxd/skills-introduction-to-github)
* **Objetivo:** Poner en práctica el flujo de trabajo estándar en GitHub:
  1. Creación y cambio a una rama de trabajo (`my-first-branch`).
  2. Adición y edición de archivos mediante commits documentados (`PROFILE.md`).
  3. Apertura de un Pull Request con título y descripción para proponer cambios.
  4. Fusión formal (*Merge*) del Pull Request hacia la rama `main` e integración automatizada con GitHub Actions.
* **Hito alcanzado:** Culminación satisfactoria del ejercicio guiado por el bot oficial de GitHub y obtención de la insignia de actividad *YOLO*.
